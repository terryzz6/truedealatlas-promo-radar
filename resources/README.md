# Reusable Data Resources

This directory contains source-traceable exports from the TrueDealAtlas public-offer index:

- [`official-offers.csv`](official-offers.csv) is a machine-readable snapshot.
- [`official-offers.md`](official-offers.md) explains the fields, provenance, refresh command, and reuse boundary.

The export keeps the official destination URL, the official source page URL, and the UTC fetch timestamp beside every row. It is intended for research, comparison, and reproducible examples; verify current terms at the source before relying on any row.
