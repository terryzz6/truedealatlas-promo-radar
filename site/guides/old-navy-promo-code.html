Classify the offer before testing it

Label what you see as one of four things: an automatic sale, a visible promo code, an account-only benefit, or a payment-card benefit. Only the second category gives you a code to enter. The other three may change the price without a code.

Also record the date, eligible category, minimum spend, account requirement, and payment requirement. If the official page does not state one of those fields, mark it unknown rather than guessing.

Use a five-line checkout record

For one exact cart, write down the official offer wording, the item subtotal before the promotion, the code entered or "no code shown," the checkout message, and the final total before payment. This creates a result another shopper can reproduce without relying on a screenshot of an old headline.

Change only one variable at a time. If you swap the item, account, shipping method, and code together, you cannot tell which condition caused the discount to appear or fail.

Stop when the evidence stops

Do not publish or share a code when it appears only on a third-party page, when the official terms are unavailable, or when checkout rejects it. A failed code is not a prompt to invent a spelling variation. It is a failed result for that cart and date.
